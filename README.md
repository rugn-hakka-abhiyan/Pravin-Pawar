# Pravin S. K. Pawar — GitHub Pages Website

This is a responsive Marathi personal website starter for GitHub Pages.

## Files
- `index.html` — complete website (HTML, CSS and small JavaScript)
- `assets/pravin-pawar.png` — supplied profile photograph
- BSP elephant symbol and leader portraits are displayed from Wikimedia Commons hosted image URLs; source/license credits are included in the page.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `pravin-pawar-website`.
2. Upload `index.html`, the `assets` folder, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. GitHub will publish the website at `https://YOUR-USERNAME.github.io/pravin-pawar-website/`.

## Before publishing
Replace the contact placeholders in `index.html` with verified official phone, email and office address. Add real event photographs in the gallery. Review all biography and political details for accuracy. The contact form is currently informational only; it is not connected to a form service or database. Leader portraits and the BSP elephant symbol are loaded from Wikimedia Commons, so an internet connection is needed to display those images. Their attribution and license links are included on the page.

The design is an original implementation inspired by the broad content structure of the reference site, not a copy of its text, branding or code.
